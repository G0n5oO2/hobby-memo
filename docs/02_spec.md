## 1. 追加・改善する機能名
　カレンダーをつける

## 2. 判断理由
　日記の付け忘れると今の状態では継続とならなくなってしまうため。

##　3.画面フローへの影響
　01_specの画面フローの主要アクションで、継続日記をつけ忘れてもカレンダーの日付をクリックすることでその日の記録を後からでもつけれるようにする

##　4.新しいイレギュラーケース

1. 空っぽ：
　日記が書かれなかったカレンダーの日付には、印が付かないようにする
　文字を入れなくても記録できるように、顔の絵文字(笑っているもの、泣いているものなど5種類くらい)を表示させ、それを押せば登録されるようにする
2. 過剰：
　１日に記録できる日記は１回までにする
3.悪意：
　継続日記を登録できないようにする
4. 中断：
　今まで打ってた記録は消されてはじめから書き直しになる
5. 別人：
　今までの日記をカレンダーの日付をクリックすることで見返しを出来るようにする

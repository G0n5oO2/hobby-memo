## 技術環境（固定・変更しない）
- フロントエンド：Vite（React または Vanilla JS）
- デプロイ先：Vercel（Hobbyプラン）
- データベース：Vercel経由のPostgres（実体はNeon）
- ORM：Prisma
- API：Vercel Functions（api/ フォルダ経由。ブラウザから直接DBには接続しない）
- 環境変数：.env.local に格納（Vercel Dashboard から取得）
- 保存方式：Postgres
## 1. ターゲットユーザー（具体的な1人）

- 人口統計（年齢・職業・環境）：
  20歳・文系大学生・趣味探し中(三日坊主)

- 行動（いつ・どこで・どの端末で）：
  休日はずっと部屋でスマホをいじるか寝るかの二択

- 心理（何に不満・どんな言葉で検索）：
  周りは部活や試験勉強などをしているが自分は何もせずに一日が終わり、周りと比べても充実していないと焦る
　「趣味　探し方」で検索

## 2. 課題（1文で言い切る）

趣味探し中の大学2年生は土日休みや夏休みなどの長期休みに、何か新しい事をしたいがやりたいことの見つけ方が分からない、という課題がある。

## 3. 解決策（1文で）

このアプリは趣味を提案し継続を手助けすることで、上の課題を解決する。

## 4. 画面フロー（5ステップ）

① 入口：インスタグラムやYouTubeなどのSNSでの広告
② 最初の画面：性別・年齢・きゅみのある内容(資格・制作など)の入力画面
③ 主要アクション：軽い性格診断からその人に合った趣味の提案(趣味・資格取得など)
　　　　　　　　　 一つの趣味ごとにオリジナルのキャラクターを作成する(継続していくことでご飯を与えたりや着替えをすることが出来る)
　　　　　　　　　 始めやすさをレベル別に分けて紹介
　　　　　　　　　 やりたいことが見つかったら、始めた日からの成長日記みたいなものをつけることが出来る
④ 結果の表示：自分がやってみたい趣味を見つけることができ、日記をつけていくことで継続を叶えることができるようになる
⑤次の行動／出口：達成できたことやどうやって達成できたのかをみんなに共有することで、他の人の目標達成にもつなげる

## 5. イレギュラーケース

1. 空っぽ（何も入力せず押したら）：
   今からでも始めやすい趣味をいくつか提案
　 検索欄に気になるワードを入れることでそのワードに関連する趣味を提案
2. 過剰（想定の10倍を入れたら）：
   軽い性格診断に加えて、より性格を絞れる項目を入れる
3. 悪意（変な文字列を入れたら）：
   次に進まないようにする
4. 中断（途中で閉じたら）：
   途中で閉じてしまったところから開始
5. 別人（想定と違う人が使ったら）：
   最初の画面での年齢入力の際に、想定と違う場合に合う趣味を探せるか分からないというような注意書きを表示
